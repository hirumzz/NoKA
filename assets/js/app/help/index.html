Gateway Navigation & Menu Guide

Dashboard

Displays real-time status of your active Kong connection (Postgres health, configuration synchronicity, node details) along with visual charts tracking requests/second, top-hit endpoints, and slowest paths.

Info

Presents a clean, overview grid of your Kong cluster specs (ID, version, hostname, database adapter). It also extracts live Prometheus latency statistics, resolving metric IDs into actual human-readable paths (e.g. /my-service).

Services

Allows you to manage upstream APIs or microservices. A service object represents your backend API, defining the upstream URL, protocol, and connection timeouts where Kong will forward matched requests.

Routes

Defines how incoming client requests map to your services. A Route matches criteria (like path prefixes, methods, or headers) and forwards the request to its parent service. Note: At least one matching criteria is required by Kong.

Consumers

Represents a client or consumer of your API. Used to attach authentication credentials (like API keys, JWT, Basic Auth) and apply granular rate limiting or Access Control List (ACL) grouping rules per client.

Plugins

Middleware modules that run during request execution. Plugins handle cross-cutting concerns like security, traffic throttling, log forwarding, and header transforms. They can be applied globally, or scoped to specific services/routes.

Vaults, Keys & Key Sets (Kong 3.x+)

Configure backend vault adapters (like HashiCorp Vault, AWS Secrets Manager) to securely store system secrets. Keys and Key Sets manage cryptographic identities (like JWK, public keys) used for token verification.

Unicode Glyph Collision

You might have previously noticed the Chinese character "凛" showing up in dashboard lists. Here is the technical detail:

  • The Cause: In the older Material Design Icons font, the icon class mdi-clock-alert was mapped to code point \uF954.
  • The Collision: \uF954 is also mapped in standard CJK Compatibility Ideographs as the character "凛" (meaning cold/severe).
  • The Fallback: If the web font is overridden or delayed during loading, browsers fall back to system fonts, rendering the compatibility character glyph.
  • The Fix: We replaced mdi-clock-alert with the safe code point icon mdi-timer-off (\uF51E), which sits completely outside the CJK range.

How to configure a Route

  1. Navigate to Services and create a Service.
  2. Inside your Service details, click Add Route.
  3. Define at least one matching rule (e.g. Paths = /my-api).
  4. Kong will now route all traffic matching host:port/my-api to your Service.
